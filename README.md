# ptt-instrumentos-governo-digital-e-agentico
Produto Técnico Tecnológico (PTT) contendo a Base de Dados com 909 instrumentos governamentais e de Inteligência Artificial para indução da maturidade em Governo Digital e Agêntico na Educação. Desenvolvido com metodologia LACA no Mestrado Profissional do Instituto Serzedello Corrêa (ISC/TCU). Autor: Tiago Souza.
